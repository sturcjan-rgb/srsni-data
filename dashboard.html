      Poznámky

      Automatické obnovování — data zápasů stahuje GitHub Action season-scraper v repu srsni-data každé 2 hodiny a commitne je do season-2026-27.json. Tenhle dashboard si ten soubor tahá živě při každém otevření, takže žádnou ruční aktualizaci nepotřebuje.
      srsni-truth — v repu je hotový Python systém (SQLite + MCP server pro Claude Code se 4 nástroji). Web portál (build_site.py) zatím čeká na jednorázové ruční zapnutí GitHub Pages v nastavení repa (Settings → Pages → Source → GitHub Actions).
      Přímé otevření FIBA endpointu v prohlížeči vrací 403 — očekávané chování (dokumentovaný CORS/access quirk), live analytics app to řeší proxy fallback řetězcem.
      Tento dashboard si data tahá živě ze season-2026-27.json při každém načtení · Refresh = obnov stránku
